# Meetings & Cadence - Team 2 (PawLink)

## Cadence

| Ceremony | When |
| :--- | :--- |
| Sprint Planning | Sprint boundary |
| Sprint Review | Sprint boundary |
| Sprint Retrospective | Sprint boundary |
| Daily Standup | async, Slack |
| Backlog Refinement | Mid-sprint |

The Sprint Review, Retrospective, and Planning for the next iteration will be held as one meeting at the transition between sprints.

## Meeting records

| Ceremony | File |
| :--- | :--- |
| Planning | `meetings/sprint-NN/planning.md` |
| Review | `meetings/sprint-NN/review.md` |
| Retrospective | `meetings/sprint-NN/retrospective.md` |

- **Planning** - Sprint Goal in one sentence, committed issues with owners.
- **Review** - what was demoed, Done vs. carried over, backlog changes.
- **Retrospective** - Start / Stop / Continue, and one action item with a
named owner. The next retrospective opens by checking it.
